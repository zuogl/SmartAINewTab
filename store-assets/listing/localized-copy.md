## `zh_CN` — 简体中文

### 名称

`SmartAINewTab`

### 简短说明

`本地优先的 Chrome 书签工作台：快速搜索、可逆整理、链接体检与可选 AI。`

### 详细说明

SmartAINewTab 把 Chrome 新标签页变成一个本地优先的书签工作台。搜索、整理和维护已有
书签时，Chrome 原生书签始终是事实来源。

主要功能：

- 跨全部书签快速搜索，并说明每个结果为什么命中；
- 用分类、分组、排序和标签建立可视化书签首页；
- 拖拽、批量整理和自然语言命令支持预览、撤销与重做；
- 检查重复、失效和跳转链接，批量修改前先确认；
- 导出和恢复完整 JSON 备份；
- 可选 BYOK AI：你选择 Provider、模型和 API Key，Key 只保存在本机；
- 自定义背景、时钟和小组件。

不用登录、也不用配置 AI，即可使用新标签页、书签显示、拖拽、本地搜索和本地备份。
扩展不会投放广告，也不会出售用户数据。需要访问网站的功能只在你主动使用时申请运行时
权限；拒绝授权不会影响本地功能。

加密云备份会分阶段开放。是否可用以扩展内显示的状态为准，不会因为商店文案而默认启用。

## `en` — English

### Name

`SmartAINewTab`

### Short description

`A local-first Chrome bookmark workspace for search, reversible organization, link checks, and optional AI.`

### Detailed description

SmartAINewTab turns Chrome's new tab page into a local-first workspace for your bookmarks. Search,
organize, and maintain your existing collection while Chrome's native bookmarks remain the source
of truth.

Key features:

- Search across all bookmarks with visible evidence for every match;
- Build a visual home page with categories, groups, ordering, and tags;
- Preview, undo, and redo drag-and-drop, bulk organization, and natural-language commands;
- Find duplicate, unavailable, and redirected links before applying confirmed repairs;
- Export and restore a complete JSON backup;
- Optional BYOK AI: choose the provider, model, and API key; the key stays on this device;
- Customize backgrounds, clocks, and widgets.

No account or AI setup is required for the new tab page, bookmark display, drag-and-drop, local
search, or local backup. SmartAINewTab does not serve ads or sell user data. Website access is
requested at runtime only when you start a feature that needs it, and declining access does not
break local features.

Encrypted cloud backup is released in stages. The extension itself shows whether it is available;
the store listing does not enable it by default.

## `ko` — 한국어

### 이름

`SmartAINewTab`

### 짧은 설명

`검색, 되돌릴 수 있는 정리, 링크 점검, 선택형 AI를 제공하는 로컬 우선 Chrome 북마크 작업 공간.`

### 상세 설명

SmartAINewTab은 Chrome 새 탭을 로컬 우선 북마크 작업 공간으로 바꿉니다. 검색, 정리,
유지 관리를 수행하는 동안 Chrome 기본 북마크는 계속 원본 데이터로 유지됩니다.

주요 기능:

- 모든 북마크를 검색하고 각 결과의 일치 근거 표시;
- 카테고리, 그룹, 순서, 태그로 시각적인 북마크 홈 구성;
- 드래그, 일괄 정리, 자연어 명령의 미리보기·실행 취소·다시 실행;
- 중복, 사용할 수 없는 링크, 리디렉션을 확인한 뒤 복구;
- 전체 JSON 백업 내보내기 및 복원;
- 선택형 BYOK AI: Provider, 모델, API Key를 직접 선택하며 Key는 기기에만 저장;
- 배경, 시계, 위젯 사용자 지정.

새 탭, 북마크 표시, 드래그, 로컬 검색, 로컬 백업은 계정이나 AI 설정 없이 사용할 수
있습니다. 광고를 제공하거나 사용자 데이터를 판매하지 않습니다. 웹사이트 접근은 필요한
기능을 직접 시작할 때만 런타임 권한으로 요청됩니다.

암호화 클라우드 백업은 단계적으로 제공되며 실제 사용 가능 여부는 확장 프로그램 안에 표시됩니다.
